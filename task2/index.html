Task 2 – выполнение через telnet

Сервер: u82590.kubsu-dev.ru
Порт: 80 (HTTP)
Команда подключения: telnet u82590.kubsu-dev.ru 80
После каждого запроса обязательно два нажатия Enter (пустая строка) для отправки заголовков.

GET / HTTP/1.0

Ответ (заголовки + тело):

Date: Sun, 07 Jun 2026 22:21:11 GMT
Server: Apache/2.4.58 (Ubuntu)
Vary: Accept-Encoding
Content-Length: 335
Content-Type: text/html; charset=UTF-8

PHP is working!<br />
<b>Fatal error</b>:  Uncaught PDOException: SQLSTATE[HY000] [1045] Access denied for user 'u68592'@'localhost' (using password: YES) in /home/u82590/www/index.php:6

#0 /home/u82590/www/index.php(6): PDO->__construct()
#1 {main}
    thrown in <b>/home/u82590/www/index.php</b> on line <b>6</b><br />
Описание: Установлено telnet-соединение с сервером. Отправлен HTTP-запрос методом GET по протоколу HTTP/1.0 к корневому ресурсу /. Заголовок Host обязателен для виртуальных хостов. В ответе сервер вернул статус 200 OK, заголовки и тело. Тело содержит сообщение об ошибке PHP (не удалось подключиться к БД), но сам факт получения ответа доказывает работоспособность сервера. Скриншот показывает весь сеанс.

Скриншот показывает начало HTML-кода этой страницы. Заголовок Content-Type: text/html; charset=UTF-8 указывает на тип и кодировку.

3. Размер file.tar.gz (HEAD, без скачивания)

Запрос:

HEAD /web-backend/task2/file.tar.gz HTTP/1.1
Host: u82590.kubsu-dev.ru

Ответ:

HTTP/1.1 200 OK
Date: Sun, 07 Jun 2026 22:25:02 GMT
Server: Apache/2.4.58 (Ubuntu)
Last-Modified: Sun, 07 Jun 2026 22:20:31 GMT
ETag: "2c47-653b14d53b9a7"
Accept-Ranges: bytes
Content-Length: 11335
Content-Type: application/x-gzip
Описание: Метод HEAD используется для получения только заголовков без тела ответа. Это позволяет узнать размер файла (поле Content-Length) без его загрузки. В ответе видим, что файл file.tar.gz имеет размер 11335 байт. Также сервер сообщает тип содержимого application/x-gzip и поддерживает частичную загрузку (Accept-Ranges: bytes).

4. Медиатип /image.png

Запрос:

HEAD /web-backend/task2/image.png HTTP/1.1
Host: u82590.kubsu-dev.ru

Ответ:

HTTP/1.1 200 OK
Date: Sun, 07 Jun 2026 22:25:42 GMT
Server: Apache/2.4.58 (Ubuntu)
Last-Modified: Sun, 07 Jun 2026 22:20:31 GMT
ETag: "290a-653b14d53b9a7"
Accept-Ranges: bytes
Content-Length: 10506
Content-Type: image/png
Описание: Аналогично предыдущему пункту, метод HEAD для файла image.png. Заголовок Content-Type: image/png определяет медиатип (MIME-тип) как PNG-изображение. Размер файла — 10506 байт. Это подтверждает, что на сервере действительно лежит графический файл.

5. Отправить комментарий в /index.php (POST)

Запрос:

POST /web-backend/task2/index.php HTTP/1.1
Host: u82590.kubsu-dev.ru
Content-Type: application/x-www-form-urlencoded
Content-Length: 13

comment=Hello

Ответ:

HTTP/1.1 404 Not Found
Date: Sun, 07 Jun 2026 22:26:07 GMT
Server: Apache/2.4.58 (Ubuntu)
Content-Length: 55
Content-Type: text/html; charset=UTF-8

Array
(
    [comment] => Hello
)

Привет, мир!1
Описание: Отправлен POST‑запрос к скрипту index.php с параметром comment=Hello в теле. Несмотря на то, что сервер вернул статус 404 Not Found (сам скрипт, вероятно, не предназначен для прямого вызова), скрипт всё равно выполнился и вывел содержимое массива $_POST и строку "Привет, мир!1". Это демонстрирует, что PHP обработал запрос и данные были переданы.

6. Получить первые 100 байт file.tar.gz (Range)

Запрос:

GET /web-backend/task2/file.tar.gz HTTP/1.1
Host: u82590.kubsu-dev.ru
Range: bytes=0-99

Ответ:

HTTP/1.1 206 Partial Content
Date: Sun, 07 Jun 2026 22:27:11 GMT
Server: Apache/2.4.58 (Ubuntu)
Last-Modified: Sun, 07 Jun 2026 22:20:31 GMT
ETag: "2c47-653b14d53b9a7"
Accept-Ranges: bytes
Content-Length: 100
Content-Range: bytes 0-99/11335
Content-Type: application/x-gzip

[бинарные данные – первые 100 байт архива]
Описание: Использован заголовок Range: bytes=0-99 для запроса только первых 100 байт файла. Сервер ответил статусом 206 Partial Content (частичное содержимое), указал точный диапазон в Content-Range и прислал 100 бинарных байт. Это стандартный механизм для докачки файлов и потоковой передачи.

7. Определить кодировку /index.php

Запрос:

HEAD /web-backend/task2/index.php HTTP/1.1
Host: u82590.kubsu-dev.ru

Ответ:

HTTP/1.1 404 Not Found
Date: Sun, 07 Jun 2026 22:27:37 GMT
Server: Apache/2.4.58 (Ubuntu)
Content-Type: text/html; charset=UTF-8
Описание: Запрос HEAD к тому же скрипту index.php. В заголовке ответа Content-Type: text/html; charset=UTF-8 явно указана кодировка символов UTF-8. Таким образом, мы определили, что сервер отдаёт страницы в кодировке Unicode, что обеспечивает корректное отображение любых символов.
